# 麻雀成績管理アプリ（PWA）

## 内容
- 最大6人、初期50試合、10試合単位で追加
- 試合ごとの参加・不参加切り替え、素点入力
- 素点・チップの両方で±対応テンキー
- 累計・平均・参加回数・最終収支ランキング
- レート設定
- localStorageによる自動保存
- JSONバックアップ／復元、CSV出力
- オフライン利用向けService Worker

## iPhoneで使う手順
1. このフォルダ内のファイル一式を、HTTPS対応の静的ホスティング（例：GitHub Pages、Netlify等）へアップロードします。
2. 公開されたURLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」を選びます。
4. ホーム画面のアイコンから起動できます。

PWAのインストールとオフラインキャッシュにはHTTPSでの公開が必要です。ローカルHTMLをファイルアプリから開いただけでは、ホーム画面アプリとしての全機能は動作しません。

## データ保存について
入力内容は同じブラウザ／アプリ領域のlocalStorageに自動保存されます。ブラウザデータの消去、アプリ削除、端末故障などに備え、設定画面から定期的にJSONバックアップを保存してください。CSVは表計算ソフトで確認・集計するための出力です。

## 注意
- 現在の版は端末内保存で、クラウド同期はありません。
- 同じ人の表記変更は「名前変更」、別人に交代する場合は「別人に交代」を使います。
- 試合の素点合計が0点かどうかは各試合の判定欄に表示されます。
